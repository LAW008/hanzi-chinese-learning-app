# Hanzi — Chinese learning app

A small, beginner-friendly Mandarin vocabulary app for English speakers. It runs as a static website with no dependencies.

## Run locally

Open `index.html` in a modern browser. Pronunciation uses the browser's Web Speech API and works best when a Chinese voice is installed.

## Features

- Browse beginner vocabulary with English definitions, pinyin, and example sentences.
- Hear words spoken in Mandarin.
- Practice with flashcards and mark familiar words as learned.
- Take a five-question multiple-choice quiz.
- Track learned words, quiz best score, and practice progress in browser storage.
